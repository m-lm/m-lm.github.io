Bipartite Question-Oriented Graph, or BiQOG, is an approach which leverages a bipartite graph structure encoding relationships between LLM-generated questions and document passages to improve comprehensive retrieval in multi-hop settings, useful for downstream applications like RAG and question answering.

This research project was completed as part of my honors thesis at the University of Arkansas, and the full thesis can be found here: [Towards Multi-Hop Retrieval Using Bipartite Question-Oriented Graphs](https://scholarworks.uark.edu/elcsuht/32/).
